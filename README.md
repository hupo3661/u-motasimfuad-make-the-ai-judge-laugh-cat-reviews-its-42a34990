One funny single-line one-star review written by a house cat about its human: the closed bathroom door, an hour of screaming outside it, and a walk-away the second it opens. The program writes the line to `/output/entry.txt`: a single line, 124 characters, deterministic, no network, no randomness.

> One star. He closed the bathroom door on me, so I screamed outside it for an hour, then walked away the second he opened it.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`MAKEFUN_OUTPUT_DIR` overrides the output directory (default `/output`). The program validates the line before writing it: one line, 1–200 characters, not blank.
